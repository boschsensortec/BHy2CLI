# UDF Utilities

Small helper utilities for working with Unified Data Format (UDF) files.

## Included Tools

- **udf2csv**: Convert UDF files to CSV format for easy viewing and analysis
- **udf_updater**: Utility to update or manipulate UDF file metadata and content

## Usage

Run the executables directly from the command line:

```
./udf2csv input.udf output.csv
./udf_updater [options] input.udf
```

## Requirements

These are precompiled binaries. Ensure you have:
- Windows 7 or later (for .exe files)
- Or the corresponding binary for your platform (Linux, macOS)
- Microsoft Visual C++ Redistributable (if required for your binary version)
